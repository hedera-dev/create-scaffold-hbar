# create-scaffold-hbar

This package is an alias. The CLI lives in **[scaffold-hbar](https://www.npmjs.com/package/scaffold-hbar)**.

```bash
npx scaffold-hbar@latest
```

`npm create scaffold-hbar@latest` keeps working because `npm create <x>` resolves to
`create-<x>` — that is the only reason this package is still published.
